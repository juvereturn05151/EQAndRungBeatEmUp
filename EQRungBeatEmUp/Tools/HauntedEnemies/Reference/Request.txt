ANIMATION FRAME COUNT GUIDELINES
==================================================

Do NOT make them too sparse, but also do not overdo the frame count.

This is a beat ’em up, so prioritize readability.

Suggested ranges:
- Idle: 4–6 frames
- Walk: 6–8 frames
- Basic attacks: 4–8 key frames
- Special attacks: 5–10 key frames
- Hurt: 2–4 frames
- Knockdown / get-up: 4–8 frames
- Death: 4–8 frames
- Warp: 4–8 frames

If needed, use fewer frames for mock-up production, but keep all critical motion represented.
