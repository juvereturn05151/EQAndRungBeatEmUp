# Character 2 artwork provenance

Generated with the built-in `image_gen.imagegen` tool, transparent backgrounds enabled. References: the supplied concept image and existing `BlueShirtGuy_Idle2_01.png` / `BlueShirtGuy_Attack1_06.png`. Saved project sources: `Assets/ArtAssets/Characters/Character2/Character2_Source.png` and `Guardian_Source.png`. Individual gameplay sprites and the native preview are in the same folder.

`Tools/Character2/prepare_art.py` extracts transparent connected components from the generated sheets, preserves their pixels, normalizes the body scale to BlueShirtGuy, and places them on 128×128 canvases using nearest-neighbor resizing. VFX cells use 256×256 canvases. A trimmed warning-ring asset supplies exact projected bounds. This processing does not redraw the character or substitute procedural character art.
