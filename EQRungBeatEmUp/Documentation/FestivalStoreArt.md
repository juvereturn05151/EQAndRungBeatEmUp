# Festival store art

Generated with the built-in imagegen tool, using transparent backgrounds. Original alpha is preserved. Unity imports both as single sprites, point filtered, uncompressed, with a bottom-center pivot. The gameplay width is set in `Prologue.asset` rather than baked into the images.
